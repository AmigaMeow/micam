# 移动端适配说明

> v0.6.0 新增

## 一、适配的断点

| 断点 | 设备 | 布局 |
|---|---|---|
| ≤640px | 手机竖屏 | 抽屉式侧边栏 |
| 641-1024px | 平板 | 窄侧边栏 |
| ≤812px + 横屏 | 手机横屏 | 紧凑布局 |

## 二、主要变化

### 2.1 抽屉式侧边栏（手机）

桌面端侧边栏固定显示 208px，手机上：
- 默认隐藏（`translateX(-100%)`）
- 顶部加**汉堡菜单按钮**
- 点击展开，带遮罩
- **点击菜单后自动收起**
- 支持**边缘右滑打开**、**左滑关闭**

### 2.2 触摸优化

- 按钮最小高度 36px（移动端 44px 更佳）
- 云台按钮从 42px 放大到 **52px**（关键！）
- 去掉 hover 效果（`@media (hover:none)`），改用 `:active` 缩放反馈
- 禁用双击缩放（`maximum-scale=1`）

### 2.3 安全区适配

适配刘海屏/圆角屏：

    .header { padding-top: env(safe-area-inset-top) }
    .content { padding-bottom: env(safe-area-inset-bottom) }
    .toast { bottom: calc(24px + env(safe-area-inset-bottom)) }

### 2.4 其他

- 设备卡片：单列（手机上两列太挤）
- 播放器控制条：按钮均分宽度
- 弹窗：宽度 `100vw - 32px`
- 表格：横向滚动容器
- Toast：底部显示（拇指够得到）

1. **浏览器**：F12 → 设备模拟 → 选 iPhone/Android
2. **真机**：手机浏览器访问 `http://<NAS>:8900`
3. **飞牛 App**：手机飞牛客户端打开插件

## 五、已知限制

- 左滑手势只在屏幕左侧 30px 内触发（避免与浏览器返回手势冲突）
- 横屏时播放器高度受限（`max-height: calc(100vh - 200px)`）
