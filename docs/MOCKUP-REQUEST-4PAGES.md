# 三、账号管理（Accounts）

**目标**：管理小米账号，让用户理解凭据机制并能备份恢复。

## 当前布局（已实现）

```
账号管理                                  [扫码添加]      │
Accounts                                                  │
                                                          │
┌─ 👤 小米账号 ───────────────────────────────────────────┐
│  用户 ID        添加时间        登录      会话           │
│  ─────────────────────────────────────────────────────  │
│  270246410      2026-09-14      已登录    正常           │
│  1327019923     2026-09-14      已登录    正常           │
└─────────────────────────────────────────────────────────┘

┌─ 🔑 凭据说明 ───────────────────────────────────────────┐
│  1. passToken（长期，登录一次即可）                      │
│  2. serviceToken + ssecurity（短期，自动续期）           │
│  3. 设备 P2P 凭据（有效期 ≥24h，自动刷新）               │
└─────────────────────────────────────────────────────────┘

┌─ 💾 凭据备份 ───────────────────────────────────────────┐
│  [导出凭据]  [导入凭据]  [查看备份]                      │
```

## 需要你决定的

```
① 账号列表用【表格】还是【卡片】？现在是表格。

```

# 五、给效果图生成的建议

## 优先级

```
P0  设置页      —— 最长最复杂，且和其他页有耦合
P1  存储监控    —— 数据密集，图表多，值得设计
P1  账号管理    —— 涉及安全，要让人看得懂
P2  开发者页    —— 受众小，保持简洁即可
```

## 每页建议出几张

```
设置页    2 张：主列表 + （如果做 Tab）某个 Tab 特写
存储监控  1~2 张：主视图 + （如果加趋势图）图表特写
账号管理  2 张：账号列表 + 扫码添加流程
开发者页  1 张：主视图
```
