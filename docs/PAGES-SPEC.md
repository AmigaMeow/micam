## 五、AI 智能 ⭐ **最需要你出效果图的页面**

**目标**：让用户**越来越少需要打开监控**。

### 5.1 架构（四层，按你的规格）

```
摄像头
  ↓
本地 AI（帧差 + YOLO 检测）        ← 免费、实时、7×24
  ↓
事件库（结构化）                   ← 已有，是 AI 的输入
  ↓
规则引擎（决定是否值得进一步分析）    ← 省成本的关卡
  ↓
外部视觉大模型（DeepSeek Flash）     ← 理解「发生了什么」
  ↓
─────────────────────────────
搜索 / 调查 / 摘要 / 告警 / 自动化
```

**核心原则**：

```
便宜、实时、重复  ->  本地模型
复杂、偶发、理解  ->  外部大模型
搜索、统计、过滤  ->  本地事件库
```

### 5.2 页面结构：**4 个 Tab**（不做单一 Chat 页）

```
AI 智能
├─ 概览     今日统计 + AI 处理情况 + 摘要
├─ 搜索     自然语言查询
├─ 调查     保存的长期调查 + 相似图搜索
─ 设置     本地 AI / 外部 Provider / 隐私 / 用量
```

POST /api/ai/investigate     创建/查询调���

**接口设计原则**（重要）：

```
1. Provider 抽象：业务层不关心后面是哪家模型
2. 统一输入：AI 事件包（event + keyframes + context）
3. 统一输出：summary / entities / actions / tags / importance
4. **API Key 只在 NAS 后端保存**，绝不下发到浏览器
5. 结果缓存（SHA256 + model + prompt_version）
6. 用量与成本一直记账
```
