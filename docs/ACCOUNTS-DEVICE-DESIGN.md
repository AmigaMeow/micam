## 四、「添加设备」到底是什么

小米摄像头**不能手动添加** —— 它是登录账号后由云端下发的。所以「添加设备」只有三条真实路径：

| 路径 | 说明 | 现状 |
|---|---|---|
| 登录/扫码新账号 | 该账号下的摄像头自动出现 | 已有（本轮修好了入口） |
| 接受共享设备 | 别人在米家里分享给你的设备 | 后端有 shared 标记，前端没有「接受」入口 |
| 重新发现 | 设备刚上线/刚解绑，重新拉一次列表 | 只有 /api/setup/repair，没有单账号粒度 |

**建议把按钮从「添加设备」改成「重新发现设备」**，并在空账号上明确写「该账号下没有摄像头」，
避免给了用户一个"点了能加设备"的错觉。

## 五、接口映射

| 功能 | 接口 | 状态 |
|---|---|---|
| 每账号设备清单 | /api/accounts/detail -> byAccount | 已有，前端未用 |
| 设备缩略图 | /api/live/thumb?did= | 已有 |
| 别名 | POST /api/devices/meta | 已有 |
| 隐藏/显示 | POST /api/devices/hide | 已有 |
| 该设备是否录像 | GET/POST /api/recordings | 已有 |
| 单账号重新同步 | 需新增 POST /api/accounts/sync | 缺 |
| 删除账号 | 需新增 DELETE /api/accounts（二次确认 + 自动备份） | 缺 |
| 设备分组（可选） | 需新增，或先用别名前缀 | 缺 |
