# 小米摄像头云台协议 — 实测结论（第二版）

> 实测时间：2026-09-15
> 设备：CW300（mxiang.camera.moc001，共享家庭）
> 方法：抓拍两帧 → 发指令 → 再抓拍 → **相位相关**测画面位移

---

## 一、方法学（先说清楚，避免符号约定打架）

### 1.1 测量原理

~~~
画面内容右移  <=>  镜头向左转     （通用约定）
~~~

### 1.2 自检（必做）

~~~python
base[80:190,150:330] = 随机图案
shifted = np.roll(base, 25, axis=1)   # 内容右移 25px
dx, dy = phase_shift(base, shifted)
# 必须得到 dx=+25，否则符号约定反了
~~~

**本报告的所有数据都通过了自检。**

如果你那边的结论相反，请先跑同样的自检 ——
相位相关的符号约定很容易写反（我在第一版就写反了一次）。

### 1.3 对照组

不发任何指令，观察 15 秒：

~~~
dx=+0 dy=+0   静止（angle=100 elev=68 不变）
~~~

**证明摄像头不会自己漂移，测到的位移都是指令造成的。**

## 二、已经确定的结论

### 2.1 operation 1 = 查询

~~~
回读 (100,68) -> (100,68)   位置不变
ack = angle:100 elevation:68 ok:false ret:-2
~~~

连发 4 次都不动。**op=1 = 查询状态**。

### 2.2 operation 3 = 向上

~~~
elevation 68 -> 74 -> 80     每次 +6
画面 dy = +38, +35           内容下移
~~~

**内容下移 = 镜头上抬 → op=3 = 上。**

三次独立运行完全一致。

### 2.3 operation 4 = 向下

~~~
elevation 80 -> 74 -> 68     每次 -6
画面 dy = -34, -38           内容上移
~~~

**内容上移 = 镜头下俯 → op=4 = 下。**

## 三、未确定的部分（重要）

### 3.1 operation 2 的方向在两次运行中相反

| 运行 | 起始位置 | dx 采样 | 结论 |
|---|---|---|---|
| A | angle=100（极限） | -31, -34 | 视野向右 |
| B | angle=36-47（中间） | +21,+22,+22,+21,+18 | 视野向左 |

**两次都高度一致（标准差 1.5 / 2），但方向相反。**

这不能用「符号写反」解释 —— 同一个脚本、同一次自检。

### 3.2 可能的原因

**假设 1：op=2 是「回到预设位」而不是「左转一步」**

~~~
当前位置在预设位左边 -> 向右移动
当前位置在预设位右边 -> 向左移动
~~~

能解释方向相反。但运行 B 中回读值没变（36->36, 40->40）。

**假设 2：op=2 是「开始连续转动」**

位移量应取决于时间，但每次都等 5 秒、位移稳定在 21px —— 不太像。

**假设 3：CW300 不是真机械云台**

旁证：CW300 不支持 MIoT 6.12（code -704040003），CW500 支持（能读 x,y）。
如果是电子云台（数码裁切），行为可能不规则。

### 3.3 operation 5

两次采样差异极大（+44 和 -147），**判定不稳定，暂不采用**。

### 3.4 operation 6-10

测试中摄像头连接被断开（broken pipe），无数据。需逐个用新连接测。

## 四、本次修正的插件错误

### 4.1 旧映射（错的）

~~~go
2 = 左
3 = 右        <- 错！实测是「上」
4 = 下        <- 对
5 = 上        <- 未验证，op=5 不稳定
~~~

### 4.2 新映射（基于实测）

~~~go
1 = 查询      （已确认）
2 = 左/右     （方向待定）
3 = 上        （已确认）
4 = 下        （已确认）
5 = 未定      （不稳定）
~~~

**这大概率解释了你说的「按左往右跑」** ——
如果界面把 op=3 标成「右」，实际执行的是「上」，
叠加摄像头倒装，用户看到的可能就是水平方向的错觉。

## 五、Mac 侧建议

### 5.1 先做确定性的事

1. **上/下 绑到 op=3 / op=4**（已确认，可放心用）
2. **左右继续用翻转开关**（你的方案是对的）
3. **不要**假设 op=2 一定是左

### 5.2 用 CW500 定标准映射

CW500（isa.camera.hlmax）有真机械云台 + MIoT 坐标可读，
建议等它凭据恢复后重测，用它定标准，CW300 用翻转开关适配。

### 5.3 每台摄像头独立配置（你的方案正确）

~~~
flip.pan.<did>   = 0/1
flip.tilt.<did>  = 0/1
~~~

不同安装方式本来就需要不同配置。

### 5.4 请复核你的符号自检

你测到 op=2「画面内容左移 240px → 视野向右」。
我测到 op=2「画面内容右移 21px → 视野向左」。

**建议在脚本里加合成位移自检**（np.roll 或等价），
确认「正 = 内容右移」的约定。相位相关符号反了很常见。

位移量也值得复核：

~~~
你：240px（若按 1920 宽算约 12.5%）
我：21px（480 宽，约 4.4%）
~~~

若你那边也是缩略图，240px 偏大 —— 可能量到了自动巡航或双镜头切换。
